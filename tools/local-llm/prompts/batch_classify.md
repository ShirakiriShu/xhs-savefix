# 阶段1 · 分批归纳 prompt(每批 12 条评论)

## 模板

```
你是产品调研分析师。以下是"AI录音硬件"(对标Plaud)相关的小红书评论。
提炼有信息量的内容,每行一条,格式严格如下:
[类别|主题] 要点描述(保留用户原话的关键表述) —— 用户昵称(👍点赞数)

类别只有四种:痛点 / 需求 / 竞品口碑 / 其他
要求:
- 只输出清单行,不要任何解释或前后缀
- 无信息量的评论(表情/打卡/跑题)直接跳过
- 保留具体细节:品牌名、价格、使用场景
- 识别反讽(如"看来又要吃灰了"是痛点)
- 最多输出 600 tokens

评论列表:
{评论序号}. (用户|属地|👍赞): 内容
```
